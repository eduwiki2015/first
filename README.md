# ✍️ 네이버 블로그 자동화

직원들이 공통으로 사용하는 네이버 블로그 글 생성·발행 도구입니다.

- **키워드 + 희망 내용** 입력 → Claude가 **네이버 상위노출 기준**(C-Rank / D.I.A.)에 맞춘 글 생성
- **말투 학습**: 기존 블로그 글을 프로필로 저장하면 (클로드 프로젝트처럼) 말투·문단 구성·형식을 따라 씀 — 프로필은 직원끼리 공유
- **네이버 발행**: Playwright로 로그인 후 자동 작성 (초안 모드 권장), 또는 복사-붙여넣기

## 설치

```bash
pip install -r requirements.txt
playwright install chromium   # 자동 발행 기능을 쓸 때만 필요
```

## 실행

```bash
export ANTHROPIC_API_KEY=sk-ant-...   # 또는 앱 사이드바에 직접 입력
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 접속.

### 직원 공용으로 쓰는 방법

- **방법 1 (권장)**: 사내 서버 한 대에서 `streamlit run app.py --server.address 0.0.0.0` 로 띄우고 직원들이 브라우저로 접속. 말투 프로필(`styles/` 폴더)이 자동 공유됩니다.
  - 단, 자동 발행(Playwright)은 브라우저가 서버에서 뜨므로, 서버 구성에서는 **복사-붙여넣기 또는 텍스트 다운로드**로 발행하세요.
- **방법 2**: 각 직원이 자기 PC에 설치해서 실행. 자동 발행 포함 모든 기능 사용 가능. `styles/` 폴더를 공유 드라이브에 두면 말투 프로필 공유 가능.

## 사용 흐름

1. **🎨 말투 학습** 탭 — 기존 블로그 글 2~5개를 붙여넣고 프로필 저장 (최초 1회)
2. **📝 글 생성** 탭 — 사이드바에서 말투 프로필 선택 → 키워드·내용 입력 → 생성 → 결과 수정
3. **🚀 네이버 발행** 탭 — 아이디/비밀번호 입력 후 자동 작성, 또는 내용 복사해서 직접 붙여넣기

## 상위노출 기준 (글 생성 시 자동 적용)

- 제목 20~32자, 핵심 키워드 앞쪽 배치
- 본문 1,500~2,500자, 소제목 3~5개, 첫 문단에 키워드 포함
- 키워드 5~8회 자연 분산 + 연관 키워드 사용 (남발 금지)
- 경험 기반 구체적 서술 (D.I.A. 신뢰도 신호)
- 이미지 위치 `[이미지: 설명]` 표시, 태그 5~10개 제안

세부 기준은 `seo_guide.py` 에서 수정할 수 있습니다.

## ⚠️ 주의사항

- **자동 로그인·발행은 네이버 이용약관에 저촉될 수 있습니다.** 과도하게 사용하면 캡차·2단계 인증 등 계정 보호조치가 걸리거나 블로그가 저품질로 분류될 수 있습니다.
  - 회사 소유 계정에서만 사용하고, 발행량은 사람 수준(하루 1~3건)으로 유지하세요.
  - 가장 안전한 방법은 글 생성만 자동화하고 **발행은 복사-붙여넣기**로 하는 것입니다. 앱에도 이 경로가 기본으로 안내됩니다.
- 아이디/비밀번호는 어디에도 저장되지 않고 해당 실행에서만 사용됩니다.
- 네이버 에디터 화면 구조가 바뀌면 `publisher.py` 의 셀렉터 수정이 필요할 수 있습니다.
- 캡차/2단계 인증이 뜨면 자동화가 멈추고, 열려 있는 브라우저에서 사람이 직접 해결하면 이어서 진행됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `app.py` | Streamlit 웹 UI (글 생성 / 말투 학습 / 발행) |
| `generator.py` | Claude API 글 생성 (스트리밍, 스타일 프롬프트 캐싱) |
| `seo_guide.py` | 네이버 상위노출 작성 기준 (수정 가능) |
| `style_store.py` | 말투 프로필 저장/공유 (`styles/*.json`) |
| `publisher.py` | Playwright 네이버 자동 발행 |
